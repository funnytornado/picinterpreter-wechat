# 常用语可读性验收

使用与日常资料分开的模拟器工程及至少 8 条合成常用语。包含长句、纯文字、缺图、重复图卡，以及同名、不同 ID 且图片不同的两个人物。不要将真实人物资料放入截图或测试报告。

## 可重复检查

设置 `WECHATIDE_SKILL_CLI` 指向已安装的官方 `wechatide` 命令，打开测试工程中的“常用语管理”，选择全部并清空搜索，分别选择默认和最大字号。运行：

```powershell
node scripts/weapp-readability-check.mjs '<隔离工程的绝对路径>' list
node --test scripts/saved-phrase-use-callbacks.test.cjs
```

打开合成长句的“查看整句”后，运行浮层布局检查：

```powershell
node scripts/weapp-readability-check.mjs '<隔离工程的绝对路径>' overlay
node node_modules/vitest/vitest.mjs run src/features/communication/PhrasePlaybackOverlay.test.ts src/features/communication/management.test.ts
```

第一项只读取当前模拟器页面，不注入或删除资料，也不代替人工滚动、点击和视觉核对。输出记录实际窗口宽度与字号；不通过伪造系统宽度代替布局测试。工具不可靠地支持 `:nth-child`，故按页面返回的按钮 ID 检查。

人工检查：第 7 条以后能到达；情境和搜索共同筛选；查看后返回保留筛选与搜索；查看不播报、不计数、不改变当前表达。长句、图片和操作均应在页面宽度内且可滚动到达。分别核对约 375px、768px，模拟器证据不能替代真机验收。
