## 两条备案流程必须分开

### 微信小程序备案

在微信公众平台完成，面向“图语家”这个小程序本身。该流程不由腾讯云 ICP 备案控制台代办，也不等同于未来 iOS/Android APP 备案。

准备项：

- 主体名称、统一社会信用代码和营业执照。
- 法定代表人及小程序负责人信息，以公众平台当前要求为准。
- 小程序名称“图语家”、图标、服务内容和实际服务类目。
- 功能说明：本地优先的图卡辅助沟通，不提供诊断、治疗、在线问诊、处方或药品销售。
- 用户隐私保护指引、麦克风用途、WechatSI 第三方处理说明。
- 审核人员可直接使用的操作路径；首版不要求登录。

### 微信服务类目核对

社交类目：

- 首版没有陌生人或熟人交友、社区/论坛、公开笔记、问答、直播、婚恋或直播答题，不选择社交类目。
- 把一句话复制到剪贴板，或由用户主动调起微信系统分享图片，属于点对点导出能力；小程序内没有动态、帖子、评论、关注、私信或公开用户主页，不把它描述为社交平台。
- CBoard 公共板浏览和用户公开发布属于在线 UGC 边界。首版生产配置关闭云功能时，代码必须同时隐藏公共板浏览/发布入口，并从生产路由移除公共板页面；未来启用前重新核对社交/内容类目、ICP备案、内容审核和举报处置义务。

医疗类目：

- 首版不提供公立或私立医疗机构服务、挂号缴费、报告查询、医生推荐、在线问诊、医疗科普、健康检测、药品或医疗器械展示和交易，不选择医疗类目。
- “我痛”“请叫医生”等图卡只是由使用者主动选择的日常沟通词，不构成诊断、治疗建议、医疗资讯或医疗机构服务；审核说明应明确这一点。
- 名称、介绍和页面文案不承诺康复效果，不使用“诊断、治疗、医疗咨询、医学建议、在线问诊”等服务性表述。面向可能处于照护场景的用户，不等于小程序自身在提供医疗服务。

两份 2019 年知识库可用于识别风险，但页面已明确提示内容可能过期。最终类目名称、适用范围和材料以微信公众平台提交当天显示的“小程序开放的服务类目”为准；若后台没有与普通工具相符的类目，或审核要求补充社交/医疗类目，应暂停提交并按审核意见复核，而不是选择不相符的类目。

### `tuyujia.com.cn` 网站/域名 ICP 首次备案

在腾讯云 ICP 备案控制台完成，目的是让域名可以合法解析到腾讯云中国大陆服务器，承载官网、隐私政策和 `cboard-api`。

硬性前提：

- 域名实名认证信息与备案主体一致。腾讯云注册域名在实名通过后满 3 个自然日再提交；平台若已能正常识别，可按页面结果继续。
- 购买腾讯云中国大陆地域、有公网 IP、带宽不为 0 的 CVM 或轻量应用服务器。
- 计费必须为包年包月，累计购买时长至少 3 个月；提交期间剩余有效期至少 1 个月。不是要求服务器先实际运行满 3 个月。
- 广东单位首次备案的主体负责人必须为法定代表人。

## 建议购买的首发服务器

| 项目 | 建议 |
| --- | --- |
| 产品 | 腾讯云轻量应用服务器，或同等 CVM |
| 地域 | 中国大陆，优先广州 |
| 计费 | 包年包月；建议直接购买 1 年，最低不得少于 3 个月 |
| 配置 | 2 核 4 GB 内存起步，系统盘 60 GB 以上，公网带宽大于 0 |
| 系统 | Ubuntu 22.04 LTS |
| 用途 | Caddy、Node.js 22 `cboard-api`、MongoDB 和低量日志/备份 |
| 不购买 | GPU、大模型镜像、Windows Server、香港或境外地域、按量计费实例 |

2 核 4 GB 是当前单机 Docker 方案的工程建议，不是备案法规要求。MongoDB、API 和 Caddy 同机运行时，2 GB 内存余量偏小；用户量增加后应优先拆分数据库和对象存储，而不是立刻购买 GPU。

## 广东单位首次备案材料

以下材料只上传腾讯云备案系统，不进入 Git：

- 营业执照原件或按页面要求提供的清晰材料。
- 法定代表人身份证原件正反面、有效期和视频核身。
- 法定代表人就业证明，注明入职时间和职务并加盖公司公章，以备案页面实际要求为准。
- 广东省单位互联网信息服务备案承诺书：法定代表人手写日期、正楷签名并加盖公章。
- 公司证件住所与实际通信地址，通信地址精确到门牌号或房间号。
- 至少两个不同、能长期接听审核电话的手机号，用于联系人和应急联系方式。
- 一个能长期收信的公司或负责人邮箱。
- 域名证书和域名实名认证信息截图。腾讯云注册域名若页面不要求上传，可不上传，但建议本地留档。

## 提交流程

1. 登录腾讯云 ICP 备案控制台，选择“网站/域名”，输入 `tuyujia.com.cn`。
2. 选择“新增备案 / 首次备案”，备案区域按公司证件填写广东省。
3. 选择符合条件的云资源，填写主体、法定代表人和服务信息。
4. 上传广东承诺书、就业证明及页面要求的补充材料，完成人脸核身。
5. 核对后提交腾讯云初审；审核电话必须保持可接听。
6. 腾讯云初审通过后，按工信部短信提示及时完成短信核验。
7. 等待广东管局审核；官方流程给出的通常上限为 20 个工作日。

## 备案通过后的动作

1. 把 `www.tuyujia.com.cn` 和 `api.tuyujia.com.cn` 解析到正式服务器。
2. 使用 Caddy 自动签发并续期 HTTPS 证书，只公开 80/443；MongoDB 端口不得对公网开放。
3. `www` 上线产品介绍、隐私政策、用户协议、开源说明和联系方式，内容与备案用途一致。
4. 广东网站页脚展示主体备案号，并链接 `https://beian.miit.gov.cn/`。
5. 在微信公众平台配置 `api.tuyujia.com.cn` 的 request、uploadFile 和 downloadFile 合法域名。
6. 更新隐私保护指引，再启用登录、云同步、AI、OCR、在线补图或方言云识别。
7. 网站正式开通后判断是否需要在 30 日内完成公安联网备案；仅提供 API、没有面向用户网页内容时按平台当前豁免说明处理。

## 变动依据

- **意图**：把域名、微信小程序和未来 APP 的备案概念拆开，让首次办理者可以按顺序执行。
- **决策**：先推进微信小程序备案和材料准备；购买符合资格的普通中国大陆服务器后，再提交 `tuyujia.com.cn` 网站/域名首次备案；首发不购买 GPU。
- **理由**：微信小程序备案由微信平台办理，而中国大陆服务器上的网站/API 域名需由接入商办理 ICP；当前 `cboard-api + MongoDB + Caddy` 可以由普通服务器承载。
- **证据**：腾讯云《首次备案》《备案云资源》《准备 ICP 备案域名》《广东管局备案要求》，以及当前 `cboard-api` 生产 Docker Compose。
- **附件复核**：腾讯云《网站命名建议》《前置审批相关》《备案云资源》《备案授权码》本地下载文本。
- **服务类目证据**：用户提供的微信官方知识库《什么小程序需要社交相关类目》《什么小程序需要医疗相关类目》，以及首版生产代码的路由、云功能开关和实际可见功能核对。
- **生效范围**：图语家微信小程序首发、官网和正式 API；不替代腾讯云、微信平台或广东通信管理局的最终审核结论。
